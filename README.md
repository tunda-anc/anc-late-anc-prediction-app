# ANC Late Attendance Prediction Project

## Project Overview
This project uses machine learning to predict the risk of late first antenatal care (ANC) attendance.

Late ANC attendance is defined as first ANC attendance at 13 weeks of gestation or later.

## Study Setting
Kabarak Health Centre, Nakuru County, Kenya.

## Machine Learning Model
The final prediction model is Logistic Regression with a preprocessing pipeline.

## Predictors
- Age
- Parity
- Gravidity
- Marital status
- Previous ANC attendance
- Pregnancy intention
- Distance to the health facility
- Social support
- Transport difficulty
- Previous ANC experience
- Education level
- Income level

Gestational age at first visit is not used as a predictor because it defines the outcome.

## Important Note
This application is intended for research and decision-support purposes. It is not a diagnostic tool and should not replace professional clinical judgment or community assessment.
